# Feature: ค้นหาหนังสือ 
Spec ID: SPEC-ค้นหาหนังสือ-001 | Source: SRS v0.3 | Use case: UC-01
Owner: ทีม หิวข้าว | Status: Draft v1 | Updated: 2569-10-04

## Goal
ผู้ใช้ค้นหาหนังสือด้วยชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญ 

## Scope
### In scope
- ค้นหาหนังสือด้วยชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญ หมวดหมู่หรือผู้แต่ง
### Out of scope
- ตำแหน่ง และ สถานะ ของหนังสือ (UC-03)

## Constraints
- DOM-OPAC-01 หนังสือแต่ละเล่มต้องมีรหัสประจำเล่ม เช่น Barcode หรือ Accession Number ที่ไม่ซ้ำกัน
- DOM-OPAC-02 หนังสือต้องถูกจัดหมวดหมู่ตามมาตรฐานที่ห้องสมุดกำหนด เช่น Dewey Decimal Classification (DDC)

## Requirements
- FR-ค้นหาหนังสือ-01 ระบบต้องสามารถค้นหาหนังสือได้                       
- FR-ค้นหาหนังสือ-02 หากไม่พบข้อมูล ระบบต้องแจ้ง “ไม่พบหนังสือที่ค้นหา” และแนะนำให้เปลี่ยนคำค้น   <- UC-01 exception 4a
- FR-ค้นหาหนังสือ-03 ผู้ใช้เลือกค้นหาตามหมวดหมู่หรือผู้แต่ง ระบบต้องกรองผลลัพธ์ตามเงื่อนไข   <- UC-01 alternative 3a

## Quality Requirements
- NFR-PERF-01 ผลการค้นหาควรแสดงภายใน 3 วินาที

## Acceptance Criteria
- [ ] AC-ค้นหาหนังสือ-01 (FR-ค้นหาหนังสือ-01)
      Given ระบบมีข้อมูลหนังสือ
      When  ผู้ใช้ค้นหาหนังสือ
      Then  ระบบแสดงรายการหนังสือที่ตรงกับคำค้น
