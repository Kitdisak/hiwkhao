# Feature: ชำระค่าปรับออนไลน์
Spec ID: SPEC-ชำระค่าปรับออนไลน์-007 | Source: SRS v0.3 | Use case: UC-07
Owner: ทีม หิวข้าว | Status: Draft v1 | Updated: 2569-10-06

## Goal
ผู้ใช้ที่ยืนยันตัวตนแล้ว มีหนังสือที่เกินกำหนดการคืนหนังสือ ระบบคำนวณค่าปรับรายวัน และผู้ใช้จ่ายค่าปรับออนไลน์

## Scope
### In scope
- ระบบแสดงค่าปรับ
- ระบบชำระเงิน
- ระบบบันทึกการชำระ
### Out of scope
- Payment Gateway

## Constraints
- DOM-XX-01 ค่าปรับหนังสือเกินกำหนดต้องคำนวณตามจำนวนวันที่เกินกำหนดและอัตราค่าปรับที่ห้องสมุดกำหนด
- DOM-XX-02 สมาชิกที่มีหนังสือเกินกำหนดหรือมีค่าปรับค้างชำระ อาจถูกระงับสิทธิ์การยืมตามกฎของห้องสมุด

## Requirements
- FR-ชำระค่าปรับออนไลน์-01 ระบบต้องคำนวณค่าปรับของหนังสือเกินกำหนดได้  
- FR-ชำระค่าปรับออนไลน์-02 ระบบต้องอนุญาตให้บรรณารักษ์ตรวจสอบรายการหนังสือที่เกินกำหนดคืนได้
- FR-ชำระค่าปรับออนไลน์-03 ระบบต้องอนุญาตให้บรรณารักษ์ตรวจสอบรายการหนังสือที่เกินกำหนดคืนได้
- FR-ชำระค่าปรับออนไลน์-04 นักศึกษาต้องชำระค่าปรับออนไลน์ได้

- FR-ชำระค่าปรับออนไลน์-05 หากผู้ใช้เปลี่ยนช่องทางการชำระเงิน → ระบบเปลี่ยนช่องทางการชำระเงิน  <- UC-07 alternative 3a
- FR-ชำระค่าปรับออนไลน์-06 หากการชำระล้มเหลว → ระบบไม่เปลี่ยนสถานะและให้ลองใหม่ <- UC-07 exception 3b

## Quality Requirements
- NFR-SEC-01 ข้อมูลการชำระเงินต้องส่งผ่านช่องทางที่ปลอดภัย

## Acceptance Criteria
- [ ] AC-ชำระค่าปรับออนไลน์-01 (FR-ชำระค่าปรับออนไลน์-01)
      Given ผู้ใช้มีค่าปรับ
      When  Payment Gateway ยืนยันว่าชำระสำเร็จ
      Then  ระบบเปลี่ยนสถานะเป็น “ชำระแล้ว”
