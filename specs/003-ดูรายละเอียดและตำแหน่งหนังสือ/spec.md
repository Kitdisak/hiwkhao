# Feature: ดูรายละเอียดและตำแหน่งหนังสือ 
Spec ID: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 | Source: SRS v0.3 | Use case: UC-03
Owner: ทีม หิวข้าว | Status: Draft v1 | Updated: 2569-10-04

## Goal
แสดงรายละเอียด สถานะ และตำแหน่งของหนังสือ

## Scope
### In scope
- ระบบแสดงชื่อ ผู้แต่ง ISBN หมวดหมู่
- ระบบแสดงสถานะ Available/Borrowed/Reserved
- ระบบแสดงชั้น โซน และเลขเรียกหนังสือ
### Out of scope
- ระบบแสดงวันที่คาดว่าจะคืน 

## Constraints
- DOM-OPAC-01 หนังสือแต่ละเล่มต้องมีรหัสประจำเล่ม เช่น Barcode หรือ Accession Number ที่ไม่ซ้ำกัน
- DOM-OPAC-02 หนังสือต้องถูกจัดหมวดหมู่ตามมาตรฐานที่ห้องสมุดกำหนด เช่น Dewey Decimal Classification (DDC)

## Requirements
- FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ระบบต้องให้ผู้ใช้เลือกหนังสือได้
- FR-ดูรายละเอียดและตำแหน่งหนังสือ-02 ระบบต้องแสดงชื่อ ผู้แต่ง ISBN หมวดหมู่
- FR-ดูรายละเอียดและตำแหน่งหนังสือ-03 ระบบต้องแสดงสถานะ Available/Borrowed/Reserved       
- FR-ดูรายละเอียดและตำแหน่งหนังสือ-04 ระบบต้องแสดงชั้น โซน และเลขเรียกหนังสือ

- FR-ดูรายละเอียดและตำแหน่งหนังสือ-05 หากข้อมูลหนังสือไม่สมบูรณ์ → ระบบแสดงเฉพาะข้อมูลที่มี  <- UC-03 exception 2a
- FR-ดูรายละเอียดและตำแหน่งหนังสือ-06 หากหนังสือถูกยืม → ระบบแสดงวันที่คาดว่าจะคืน  <- UC-03 alternative 3a

## Quality Requirements
- NFR-USE-01 ข้อมูลตำแหน่งต้องอ่านง่ายและเข้าใจได้

## Acceptance Criteria
- [ ] AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03)
      Given มีหนังสืออยู่ในระบบ
      When  ผู้ใช้เลือกรายการหนังสือ
      Then  ระบบแสดงรายละเอียด สถานะ และตำแหน่ง
