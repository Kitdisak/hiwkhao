# Feature: ติดตามสถานะการจองหนังสือ
Spec ID: SPEC-ติดตามสถานะการจองหนังสือ-005 | Source: SRS v0.3 | Use case: UC-05
Owner: ทีม หิวข้าว | Status: Draft v1 | Updated: 2569-10-06

## Goal
ผู้ใช้ที่ยืนยันตัวตนแล้ว สามารถตรวจสอบหนังสือที่จองกำลังรอคิว พร้อมรับ หรือหมดเวลารับแล้ว

## Scope
### In scope
- ข้อมูลการจองทั้งหมดของผู้ใช้
- ลำดับคิวและสถานะ 
### Out of scope
- ยกเลิก/ เลื่อน การจองหนังสือ

## Constraints
- DOM-XX-01 เมื่อมีผู้จองหนังสือ ระบบต้องจัดลำดับคิวตามลำดับการจองก่อน-หลัง

## Requirements
- FR-ติดตามสถานะการจองหนังสือ-01 ระบบต้องแสดงรายละเอียดหนังสือที่จองได้
- FR-ติดตามสถานะการจองหนังสือ-02 ระบบต้องแสดงสถานะ Waiting / Ready / Completed      
- FR-ติดตามสถานะการจองหนังสือ-03 ระบบต้องสามารถแจ้งเตือนนักศึกษาเมื่อหนังสือที่จองไว้พร้อมให้รับได้          
- FR-ติดตามสถานะการจองหนังสือ-04 หากหนังสือพร้อมรับ → ระบบแสดงวันหมดเขตรับหนังสือ <- UC-05 exception 2a
- FR-ติดตามสถานะการจองหนังสือ-05 หากไม่มีรายการจอง → ระบบแจ้งว่าไม่มีรายการ  <- UC-05 alternative 1a

## Quality Requirements
- NFR-ACC-01 สถานะต้องตรงกับข้อมูลการยืม-คืนล่าสุด

## Acceptance Criteria
- [ ] AC-ติดตามสถานะการจองหนังสือ-01 (FR-ติดตามสถานะการจองหนังสือ-01)
      Given ผู้ใช้มีรายการจอง
      When  เปิดหน้าการจอง
      Then  ระบบแสดงสถานะล่าสุด
