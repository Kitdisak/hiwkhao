# Feature: ติดตามสถานะการจองหนังสือ
Spec ID: SPEC-ติดตามสถานะการจองหนังสือ-005 | Source: SRS v0.3| Use case: UC-05
Owner: ทีม หิวข้าว | Status: Draft v1 | Updated: 2569-10-10

## Goal
ผู้ใช้ตรวจสอบรายการจอง ลำดับคิว และสถานะล่าสุดของหนังสือที่จองไว้

## Primary Actor
นักศึกษา / สมาชิก

## Scope
### In scope
- แสดงรายการจองของผู้ใช้
- แสดงลำดับคิวและสถานะ Waiting / Ready / Completed
- แสดงวันหมดเขตรับหนังสือเมื่อพร้อมรับ
### Out of scope
- สร้างรายการจองใหม่ (UC-04)
- ยกเลิกการจอง (การยกเลิกหนังสือไม่ปรากฏเป็น Use Case แยกในชุดนี้)

## Constraints
- ผู้ใช้ต้องเข้าสู่ระบบ
- สถานะต้องตรงกับข้อมูลการจองล่าสุด

## Requirements
- **FR-ติดตามสถานะการจองหนังสือ-01** ระบบต้องแสดงรายการจองทั้งหมดของผู้ใช้ที่เข้าสู่ระบบ
- **FR-ติดตามสถานะการจองหนังสือ-02** ระบบต้องแสดงลำดับคิวและสถานะ Waiting / Ready / Completed ของแต่ละรายการ
- **FR-ติดตามสถานะการจองหนังสือ-03** เมื่อหนังสือพร้อมรับ ระบบต้องแสดงวันหมดเขตรับหนังสือ (UC-05 Alternative 4a)
- **FR-ติดตามสถานะการจองหนังสือ-04** เมื่อไม่มีรายการจอง ระบบต้องแจ้งว่าไม่มีรายการ (UC-05 Exception 2a)

## Quality Requirements
- **NFR-ACC-01** สถานะการจองต้องตรงกับข้อมูลล่าสุด
- **NFR-USE-01** สถานะและวันหมดเขตรับต้องแสดงอย่างชัดเจน

## Acceptance Criteria
- [ ] **AC-ติดตามสถานะการจองหนังสือ-01** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** ผู้ใช้เข้าสู่ระบบและมีรายการจอง
  - **When** เปิดเมนูรายการจองของฉัน
  - **Then** ระบบแสดงรายการจองพร้อมสถานะล่าสุด
- [ ] **AC-ติดตามสถานะการจองหนังสือ-02** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** มีรายการจองสถานะ Ready
  - **When** ผู้ใช้เปิดรายการจอง
  - **Then** ระบบแสดงวันหมดเขตรับหนังสือ
- [ ] **AC-ติดตามสถานะการจองหนังสือ-03** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** ผู้ใช้ไม่มีรายการจอง
  - **When** เปิดเมนูรายการจองของฉัน
  - **Then** ระบบแจ้งว่าไม่มีรายการ
