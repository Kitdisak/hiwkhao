# Feature: จัดการสมาชิกและสิทธิ์ผู้ใช้
Spec ID: SPEC-จัดการสมาชิกและสิทธิ์ผู้ใช้-014 | Source: SRS v0.3 | Use case: UC-14
Owner: ทีม หิวข้าว  | Status: Draft v1 | Updated: 2569-10-10

## Goal
ผู้ดูแลระบบจัดการบัญชีผู้ใช้ สถานะบัญชี บทบาท และสิทธิ์ตามอำนาจที่ได้รับ

## Primary Actor
ผู้ดูแลระบบ (System Administrator)

## Scope
### In scope
- ค้นหาบัญชีผู้ใช้
- เพิ่มหรือแก้ไขข้อมูลบัญชี
- ระงับหรือเปิดใช้งานบัญชี
- กำหนด Role/Permission และบันทึกประวัติการเปลี่ยนแปลง
### Out of scope
- ตรวจสอบประวัติการใช้งานโดยละเอียด (อยู่นอกขอบเขต UC-14 และเกี่ยวข้องกับงาน Audit)

## Constraints
- Admin ต้องเข้าสู่ระบบและมีสิทธิ์จัดการผู้ใช้
- ต้องป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต
- การเปลี่ยน Permission ต้องบันทึกใน Audit Log

## Requirements
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01** ระบบต้องให้ Admin ค้นหาและเลือกบัญชีผู้ใช้เพื่อจัดการได้
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02** ระบบต้องให้ Admin แก้ไขข้อมูลและกำหนด Role/Permission ตามสิทธิ์ที่มี
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03** ระบบต้องอนุญาตให้ระงับหรือเปิดใช้งานบัญชีผู้ใช้
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04** เมื่อระงับบัญชี ระบบต้องเปลี่ยนสถานะเป็น Suspended (UC-14 Alternative 4a)
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05** หาก Admin พยายามกำหนดสิทธิ์ที่ตนไม่มีอำนาจ ระบบต้องปฏิเสธ (UC-14 Exception 5a)
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06** ระบบต้องบันทึกการเปลี่ยนแปลงบัญชีและสิทธิ์ใน Audit Log

## Quality Requirements
- **NFR-SEC-01** ต้องควบคุมสิทธิ์การจัดการบัญชีและ Permission
- **NFR-AUDIT-01** การเปลี่ยน Permission ต้องถูกบันทึกใน Audit Log

## Acceptance Criteria
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** Admin มีสิทธิ์จัดการบัญชี
  - **When** Admin เปลี่ยน Role หรือสถานะบัญชีและยืนยัน
  - **Then** ระบบอัปเดตข้อมูลและบันทึกประวัติ
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** Admin ไม่มีสิทธิ์กำหนด Permission ที่ร้องขอ
  - **When** Admin ยืนยันการเปลี่ยนสิทธิ์
  - **Then** ระบบปฏิเสธและไม่เปลี่ยน Permission
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03** (ตรวจสอบ Requirements ที่เกี่ยวข้อง)
  - **Given** Admin เลือกระงับบัญชี
  - **When** Admin ยืนยันการระงับ
  - **Then** ระบบเปลี่ยนสถานะบัญชีเป็น Suspended
